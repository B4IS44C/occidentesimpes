# Occidente · Vendedoras

Página móvil publicada con GitHub Pages. Consulta únicamente los SINPE recibidos hoy, según la hora de Costa Rica. El nombre de la vendedora se recuerda en el navegador.

La API de Firebase valida la referencia de seis dígitos y registra una sola comprobación mediante una transacción. Los datos pendientes no incluyen referencia ni SMS original. La identidad seleccionada no equivale a una autenticación; esta página permite acceso público por decisión del negocio.

El administrador agrega y elimina vendedoras desde el sistema principal. Las eliminaciones conservan el historial. No hay credenciales ni claves privadas en este repositorio.
